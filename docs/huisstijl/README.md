# Huisstijl De Hoge Wei

Upload hier het huisstijlhandboek en alles wat de designer nodig heeft om de
brochure exact na te bouwen in InDesign.

## Wat er nu in de template zit (afgeleid van fase A & B)

| Rol | Kleur | Hex |
|---|---|---|
| Rood (basis) | donkerrood | `#5A1319` |
| Rood diep | | `#480F14` |
| Lime | accent | `#C9D75F` |
| Perzik | accent | `#F8B87F` |
| Oranje | accent / markering | `#E9541F` |
| Crème | papier | `#F3ECDD` |
| Blauw | accent | `#BEE1F2` |

**Let op:** dit zijn RGB-waarden die uit de bestaande brochures zijn afgeleid.
Het logobestand zelf is opgebouwd uit één kleur: **`#4F1717`**. Dat wijkt af van
de `#5A1319` die als basisrood in de template staat — even controleren welke van
de twee de officiële merkkleur is.
Voor drukwerk zijn de officiële CMYK- of Pantone-waarden nodig — die horen in
het huisstijlhandboek. Zet ze hier neer zodra je ze hebt.

## Fonts in de template

De merkfonts uit `assets/fonts/` zijn ingebouwd; de Google Fonts zijn eruit.

| Rol | Font |
|---|---|
| Koppen (h1, h2) | Neue Haas Display Black (900) |
| Kopjes, labels, eyebrow | Neue Haas Display Bold (700) |
| Broodtekst | Neue Haas Display Roman (400) |
| Inhoudsopgave, folio | Neue Haas Display Medium (500) |
| Lead-alinea's | Calluna Italic |
| Handgeschreven quotes | Filmotype LaCrosse |

De koppen zijn iets verkleind ten opzichte van de eerdere opzet (h1 van 38
naar 31 pt, h2 van 27 naar 22 pt) omdat Neue Haas Display breder bouwt dan de
Bodoni die er als benadering stond. De designer kan dat in InDesign
finetunen.
